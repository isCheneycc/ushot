# Ushot 0.1.10

- Shows Ushot with its correct name and application icon in Screen Recording settings.
- Keeps screenshot permission associated with the installed release instead of an old development, test or backup copy.
- Separates Debug settings and application data from the release installation.
- Strengthens installation and rollback registration so only the final installed application owns the system identity.
- macOS may ask you to grant Screen Recording permission again after updating.
