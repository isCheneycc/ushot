# Ushot 0.1.16

- Keeps the text annotation border at a consistent height when committing text and reopening it for editing, including handwritten fonts and fractional canvas zoom.
- Restores focus to the application used before capture after copying, saving or cancelling a screenshot, so typing can continue without an extra click.
- Preserves focus in another application or an open Canvas editor when the user switches to it before a screenshot closes.
- Reduces region capture memory by keeping frozen backgrounds out of interactive redraws and giving cropped regions independent pixel storage.
- Defers full-image composition during transparent region confirmation and coalesces annotation renders so only one bitmap render runs per editing session.
- Resolves the latest annotations before dragging an image out and cancels delayed drag preparation when its pointer gesture ends.
