# Ushot 0.1.7

- Keeps region, window, current-display, selected-display and all-display results available as pinned screenshots.
- Captures window surfaces at native pixel geometry so previews remain crisp at their original size, including validated framing and shadows.
- Uses high-quality interpolation whenever presentation is not exactly one-to-one, avoiding scaled jagged edges.
- Adds a brief eased entrance for window and display previews, with reduced-motion behavior.
- Keeps pinned screenshots attached to the pointer across display seams and adds proportionally anchored trackpad zoom.
- Keeps window capture compatible with supported older macOS versions while using newer system capture behavior when available.
- Redesigns the color-picker card to prioritize the copy value, channels, concise metadata and clearly grouped shortcuts.
- Prevents Pin from committing while a pointer move or resize is still active.
