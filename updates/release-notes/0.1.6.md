# Ushot 0.1.6

- Adds optional control-level snapping inside captured windows and keeps targets stable in dynamic interfaces.
- Adds parent and child target selection with Option-Up, Option-Down and Option-scroll.
- Upgrades the region magnifier with pixel coordinates, selection dimensions, a one-pixel grid and snap-target context.
- Exits the color picker after a color is copied successfully.
- Prevents a transient dot when moving or resizing an existing rectangle annotation.
