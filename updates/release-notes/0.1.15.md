# Ushot 0.1.15

- Adds handwritten text using bundled Excalifont and Xiaolai for Chinese, available offline in quick tools, the Canvas editor and exports.
- Adds a hand-drawn arrow style with a nearly straight single stroke and a slender open head.
- Saves default fonts and arrow styles in Editor settings for new screenshots, while retaining temporary tool choices within the current screenshot.
- Lets region and pinned screenshot toolbars move using a high-contrast drag handle. Their position is retained through tool changes, Pin and hiding or showing the toolbar.
- Keeps handwritten arrows consistent between drawing, commit, copy and export, and supports precisely horizontal and vertical arrows.
- Changes text fonts with consistent layout and a single undo step.
