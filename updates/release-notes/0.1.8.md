# Ushot 0.1.8

- Adds an optional double-click action that copies a confirmed region and closes the capture overlay.
- Keeps active text editing focused when the field is clicked and supports hard line breaks with Shift+Return.
- Grows and wraps long text without hiding the beginning of the sentence.
- Keeps committed text padding even so its editing frame remains stable when reopened.
- Keeps every wrapped line aligned between editing and final output at fractional zoom/scale, including wide saved lines, mixed right-to-left text, emoji fallback and unusually tall fonts.
- Preserves the authored line layout and exact primary/fallback font sources in saved history. If a required font source or glyph shape is unavailable, Ushot keeps the record and reports the limitation instead of crashing, hiding it as corrupt or silently changing the result.
- Rejects inconsistent saved text geometry instead of drawing glyphs outside its owned frame.
- Groups each continuous Canvas inspector edit into one undo step and refreshes Undo/Redo immediately.
