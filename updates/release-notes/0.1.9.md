# Ushot 0.1.9

- Makes the latest Ushot improvements available through Check for Updates.
- Keeps window and display screenshot previews crisp at native size and makes their entrance feel smoother.
- Keeps pinned screenshots under the pointer while they move across displays and adds anchored trackpad pinch zoom.
- Lets every screenshot type become a pinned image and keeps region Pin output read only until its toolbar is shown.
- Improves the color picker information hierarchy and shortcut layout.
- Adds optional double-click copying for a confirmed region.
- Improves active text editing, hard line breaks, long-text wrapping, committed padding and final text-layout consistency.
- Preserves authored text layout and exact font sources in saved history, and reports unavailable resources instead of silently changing the result.
- Groups each continuous Canvas inspector edit into one undo step and refreshes Undo and Redo immediately.
