# Ushot 0.1.17

- Limits region smart snapping to the active application plus visible pinned screenshots and exposed desktop areas, preventing accidental snaps to background applications or floating panels across multiple displays.
- Keeps the previous application in snap scope right after pinning or opening Ushot Settings, and allows capturing the visible Ushot Settings window while keeping overlays and toolbars excluded.
- Adds a whole-display snap level in region mode so hovering exposed desktop snaps directly to that display and pressing Tab or Option-scrolling climbs from control and window to the full display.
- Preserves drop shadows on floating panels and ordinary windows in region and display captures when Keep window shadow is enabled, and keeps the live color picker aligned with frozen screen pixels.
- Exempts system menu-bar screen-capture indicators from freeze-stability restrictions and hardens Accessibility ownership verification and diagnostics.
