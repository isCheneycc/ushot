# Ushot 0.1.5

- Adds a configurable region-capture corner radius shared by selection, confirmation and Copy, Save and Pin output.
- Adds English and Simplified Chinese interface selection under Advanced settings, with Simplified Chinese as the default.
- Introduces a resizable Settings window with an always-visible section sidebar.
- Keeps region geometry on whole-point boundaries to prevent border and size jumps when selection finishes.
- Preserves rounded clipping while resizing, editing and exporting a region capture.
