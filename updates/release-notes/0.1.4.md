# Ushot 0.1.4

- Enables the first authenticated in-app update from Ushot 0.1.3.
- Keeps update checks manual and disables automatic downloads and system profiling.
- Verifies the complete signed feed before parsing update metadata.
- Requires an independent EdDSA signature and exact version identity for the update archive.
- Preserves the installed application when authentication, validation or installation fails.
