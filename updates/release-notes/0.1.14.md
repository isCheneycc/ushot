# Ushot 0.1.14

- Adds P as a quick Pin shortcut after selecting a region, preserving the latest annotations and normal typing in text fields.
- Keeps pinned images visible and available for selection when starting another screenshot.
- Freezes all displays by default when Color Picker starts so the screen, magnifier and copied color use the same pixels. The Color Picker settings include a persistent switch to return to live sampling.
- Cancels a frozen Color Picker session if the display configuration changes.
