# Roadmap

- Phase 0 — repository, native project, configuration, app shell, dependency container, logging and test target.
- Phase 1 — menu bar, versioned settings, permission guidance, login item and conflict-safe Carbon hot keys.
- Phase 2 — current/selected/all-display, window and region capture backed by ScreenCaptureKit and tested global geometry.
- Phase 3 — a single persistent current-screenshot panel with replacement semantics, copy, save, drag, resizing and an attached annotation toolbar.
- Phase 4 — versioned non-destructive annotation model, renderer, commands, undo and quick annotation tools.
- Phase 5 — multi-window canvas editor sharing the exact Phase 4 document and renderer.
- Phase 6 — managed-color pixel picker and point/pixel screen ruler across displays.
- Phase 7 — opt-in editable history, accessibility/localization pass, performance validation and release packaging.

Post-1.0 ideas (no first-release UI): scrolling capture, recording, GIF, delayed capture, OCR/translation and optional paid entitlements behind the existing capability boundary.
