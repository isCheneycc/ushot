## Installation, Update and Release Trust

This section covers four rollout stages with independent publication gates: historical 0.1.1 remains isolated on its absent legacy feed; published 0.1.2 (build 3) is the first `publish_update_feed=false` manual transition; published 0.1.3 (build 4) is the second manual GitHub-only transition and adds authenticated raw-XML validation, also with `publish_update_feed=false`; and feed generation, update privacy, a clean-account 0.1.3 → 0.1.4 replacement, raw-XML/exact-version/tamper rejection, active-work admission and key recovery all block the first `publish_update_feed=true` run for 0.1.4 (build 5). The complete non-Developer-ID matrix has not been completed. Record source/target versions, Git tags, asset hashes, macOS version, account type, network conditions, Screen Recording state, runtime-fork identity and relevant privacy-safe logs for every run; do not infer a pass from source presence, a successful build, CI validation, direct-download publication or appcast generation.
